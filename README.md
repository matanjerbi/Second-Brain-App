# Second Brain

זיכרון חיצוני לאנדרואיד: כל דבר שראית, חשבת או רצית לזכור, במקום אחד, עם חיפוש לפי משמעות.

## מה יש בגרסה הזו
- **שמירה מ"שתף"** מכל אפליקציה: טקסט, קישורים, צילומי מסך ותמונות, הקלטות.
- **הוספה ידנית** עם הכתבה קולית בעברית.
- **חיפוש לפי משמעות**: חיפוש עברי עם זיהוי תחיליות וריבוי, מפת מושגים מובנית, ועם מפתח API גם הרחבת שאילתה והעשרה של כל פריט במילות מפתח, כותרת ותקציר.
- **שאלה ותשובה**: "מה היה שם המסעדה ששמרתי?" מקבל תשובה במשפט עם הפריטים שעליהם היא מבוססת (דורש מפתח API).
- **צילומי מסך**: זיהוי טקסט על המכשיר (אנגלית), ועם מפתח API גם עברית ותיאור של התמונה.
- **קישורים**: שליפת כותרת ותיאור הדף אוטומטית.
- **ייבוא מוואטסאפ**: קובץ ה-ZIP או ה-TXT של ייצוא הצ'אט, ישירות מההגדרות. כפילויות מדולגות.
- **כספת**: כרטיסי אשראי, מספרי זהות, קודים ומפתחות מזוהים אוטומטית, ננעלים בטביעת אצבע ולא נשלחים ל-AI.
- **גיבוי** של כל הפריטים לקובץ JSON.

## פרטיות
הנתונים נשמרים רק בטלפון. מפתח ה-API נשמר מוצפן במכשיר ולא נמצא בקוד. רק פריטים שאינם רגישים נשלחים ל-Anthropic, וזה קורה רק כשיש מפתח מוגדר.
